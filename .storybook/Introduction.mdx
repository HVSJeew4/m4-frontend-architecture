# AdminFlow component library

Reusable components for the AdminFlow dashboard. They live in `src/components/common/`, and each one
has its stories next to it (`Button.tsx` → `Button.stories.tsx`).

- **Accessibility:** every story is checked by the a11y addon (axe). Open the
  "Accessibility" panel below a story to see the results.
- **Styling:** Tailwind CSS, the same styles as the app.
- **Data:** stories that need data use the app's mock API (MSW), so no backend is needed.
